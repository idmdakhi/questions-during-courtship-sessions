---

## درباره این بخش

این بخش شامل ابزارهای عملی، فرم‌های آماده، واژه‌نامه، منابع علمی و یادداشت‌های تکمیلی است. این پیوست‌ها به شما کمک می‌کنند تا:

- مشاهدات خود را منظم ثبت کنید.
- جمع‌بندی نهایی دقیق‌تری داشته باشید.
- با اصطلاحات تخصصی آشنا شوید.
- از منابع علمی معتبر بهره ببرید.

## نحوه استفاده

### ۱. قبل از جلسات:

- [واژه‌نامه](c-glossary.md) را مطالعه کنید.
- [فرم یادداشت جلسات](a-session-notes.md) را چاپ یا آماده کنید.

### ۲. در طول جلسات:

- مشاهدات خود را در [فرم یادداشت](a-session-notes.md) ثبت کنید.
- از [آزمون‌های استاندارد](g-standard-tests.md) در صورت نیاز استفاده کنید.

### ۳. پس از جلسات:

- [فرم جمع‌بندی نهایی](b-final-summary.md) را تکمیل کنید.
- از [منابع](d-resources.md) برای مطالعه بیشتر بهره ببرید.
