# پیوست ز — آزمون‌های استاندارد

> **معرفی ابزارهای رایج روان‌سنجی؛ با توجه به اعتبار و محدودیت هر کدام.**

---

## مقدمه

آزمون‌های روان‌شناختی می‌توانند به شناخت بهتر خود و طرف مقابل کمک کنند. اما توجه داشته باشید:

> **آزمون‌ها ابزار کمکی هستند، نه جایگزین گفتگو و مشاوره تخصصی.**

---

## آزمون‌های شخصیت

### ۱. آزمون MBTI (مایرز-بریگز)

| مورد        | توضیح                                                                               |
| ----------- | ----------------------------------------------------------------------------------- |
| **هدف**     | شناخت تیپ شخصیتی بر اساس ۴ بُعد                                                     |
| **ابعاد**   | برون‌گرا/درون‌گرا، حسی/شهودی، فکری/احساسی، قضاوتی/ادراکی                            |
| **کاربرد**  | شناخت سبک ارتباطی، تصمیم‌گیری، ترجیحات                                              |
| **محدودیت** | ساده‌سازی بیش از حد؛ پایایی بازآزمون و اعتبار پیش‌بینی آن مورد انتقاد پژوهشگران است |
| **دسترسی**  | [16personalities.com](https://www.16personalities.com)                              |

### ۲. آزمون پنج عامل بزرگ (Big Five)

| مورد        | توضیح                                                 |
| ----------- | ----------------------------------------------------- |
| **هدف**     | ارزیابی ۵ عامل اصلی شخصیت                             |
| **ابعاد**   | گشودگی، وظیفه‌شناسی، برون‌گرایی، سازگاری، روان‌رنجوری |
| **کاربرد**  | شناخت جامع‌تر شخصیت                                   |
| **محدودیت** | نیاز به تفسیر تخصصی                                   |
| **دسترسی**  | [bigfive-test.com](https://bigfive-test.com)          |

### ۳. آزمون ۱۶PF کاتل

| مورد        | توضیح                  |
| ----------- | ---------------------- |
| **هدف**     | ارزیابی ۱۶ عامل شخصیتی |
| **کاربرد**  | شناخت عمیق‌تر شخصیت    |
| **محدودیت** | نیاز به مشاور متخصص    |
| **دسترسی**  | مراکز مشاوره           |

## آزمون‌های تخصصی

> ⚠️ **هشدار:** SCL-90 و MMPI ابزارهای بالینی‌اند و برای سنجش طرف مقابل توسط غیرمتخصص طراحی نشده‌اند. استفاده از آن‌ها فقط با راهنمایی روان‌شناس بالینی توصیه می‌شود. جزئیات بیشتر: [یادداشت علمی](../00-introduction/08-scientific-notes.md).

### ۹. آزمون MMPI

## توصیه‌های استفاده از آزمون‌ها

### ۱. با مشاور مشورت کنید

قبل از استفاده از آزمون‌ها، از مشاور خود راهنمایی بخواهید.

### ۲. از تفسیر خودسرانه پرهیز کنید

تفسیر آزمون‌ها نیازمند تخصص است. از تفسیر خودسرانه پرهیز کنید.

### ۳. آزمون را معیار قطعی ندانید

آزمون‌ها **ابزار کمکی** هستند، نه **معیار قطعی** برای تصمیم‌گیری.

### ۴. نتیجه را با گفتگو تکمیل کنید

نتیجه آزمون‌ها را با گفتگو، مشاهده رفتار و مشاوره تکمیل کنید.

---

## نکته مهم

> **آزمون‌های استاندارد، تنها یکی از ابزارهای شناخت هستند.**
>
> **تصمیم نهایی باید بر پایه مجموعه اطلاعات، گفتگو و مشاوره گرفته شود.**
