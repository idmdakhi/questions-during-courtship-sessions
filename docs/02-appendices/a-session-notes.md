## نکات مهم

1. **بلافاصله یادداشت کنید:** حداکثر تا چند ساعت پس از جلسه.
2. **صادقانه بنویسید:** یادداشت‌ها فقط برای خودتان است.
3. **مثال‌ها را ثبت کنید:** پاسخ‌های واقعی، ارزش بیشتری از برداشت‌های کلی دارند.
4. **احساسات خود را ثبت کنید:** احساس شما نیز بخشی از داده‌های ارزیابی است.
5. **مرتب مرور کنید:** قبل از جلسه بعدی، یادداشت قبلی را بخوانید.
