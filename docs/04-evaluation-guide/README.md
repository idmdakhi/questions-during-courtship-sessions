# راهنمای ارزیابی

<div dir="rtl">

> **ابزارهای تخصصی برای ارزیابی پاسخ‌ها، رفتارها و نشانه‌ها**

---

## درباره این بخش

این بخش، مکمل فصل‌های شناخت است و به‌طور اختصاصی برای **ارزیابی دقیق‌تر** پاسخ‌ها، رفتارها و نشانه‌ها طراحی شده است. در این بخش، شما با:

- **نشانه‌های مثبت (Green Flags):** نشانه‌های سلامت رابطه
- **نشانه‌های نیازمند بررسی (Yellow Flags):** نشانه‌هایی که نیاز به دقت بیشتر دارند
- **نشانه‌های هشدار (Red Flags):** نشانه‌های جدی که نیازمند توجه فوری هستند
- **سؤالات پیگیری:** ابزاری برای عمیق‌تر کردن گفتگو
- **تحلیل پاسخ‌ها:** روشی برای تفسیر منسجم پاسخ‌ها

آشنا خواهید شد.

## نحوه استفاده

### ۱. قبل از جلسات

- این بخش را مطالعه کنید.
- با نشانه‌ها آشنا شوید.
- سؤالات پیگیری را تمرین کنید.

### ۲. در طول جلسات

- به نشانه‌ها **دقت کنید**.
- از **سؤالات پیگیری** استفاده کنید.
- **یادداشت‌برداری** کنید.

### ۳. پس از جلسات

- پاسخ‌ها را **تحلیل کنید**.
- **الگوها** را شناسایی کنید.
- از [چک‌لیست نهایی](../01-chapters/chapter-21-evaluation.md) استفاده کنید.

## نکات کلیدی

> **هدف ارزیابی، قضاوت نیست؛ شناخت است.**

> **هیچ نشانه‌ای، به‌تنهایی دلیل قطعی نیست.**

> **الگوها و تکرارها، مهم‌تر از موارد منفرد هستند.**

> **در صورت مشاهده نشانه‌های هشدار جدی، با مشاور مشورت کنید.**
