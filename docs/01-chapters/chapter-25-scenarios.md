# فصل ۲۵ — سناریوهای فرضی و تحلیل آن‌ها

## هدف فصل

زندگی مشترک، همیشه مطابق برنامه پیش نمی‌رود. بحران‌ها، چالش‌ها و موقعیت‌های دشوار، بخشی از واقعیت زندگی هستند. این فصل، **۱۶ سناریوی فرضی اما واقع‌بینانه** را ارائه می‌دهد که می‌توانند در زندگی مشترک رخ دهند. هدف، شناخت نحوه واکنش دو طرف در این موقعیت‌ها و ارزیابی توانایی مدیریت مشترک آن‌هاست.

در پایان این فصل باید بتوان به این سؤال پاسخ داد:

> **«در موقعیت‌های دشوار، چگونه با هم همکاری می‌کنیم و تصمیم می‌گیریم؟»**

---

## روش استفاده

برای هر سناریو:

1. **سناریو را بخوانید** (بدون بحث).
2. **هر طرف، پاسخ خود را بنویسد** (بدون مشورت).
3. **پاسخ‌ها را با هم مقایسه کنید.**
4. **درباره تفاوت‌ها گفتگو کنید.**
5. **به دنبال راه‌حل مشترک باشید.**

---

> **یادداشت:** این سناریوها فرضی‌اند و تحلیل‌ها فرضیه برای گفتگو هستند، نه تشخیص. اگر سناریویی برای یکی از شما ناراحت‌کننده بود، می‌توانید آن را کنار بگذارید.

## سناریو ۱ — اختلاف مالی

### هدف سناریو

سنجش توان دو طرف در گفتگو و توافق درباره پول، بدون سرزنش و پنهان‌کاری.

### وضعیت

شما و همسرتان درباره نحوه مدیریت مالی خانواده اختلاف دارید. یکی از شما اهل پس‌انداز است و دیگری اهل خرج کردن.

### سؤالات

1. اولین اقدام شما چیست؟
2. چگونه این اختلاف را حل می‌کنید؟
3. چه توافقی برای آینده می‌کنید؟
4. اگر اختلاف ادامه پیدا کند، چه می‌کنید؟

### تحلیل

| جنبه       | نکات کلیدی                    |
| ---------- | ----------------------------- |
| **مدیریت** | گفتگو، توافق، شفافیت          |
| **احترام** | احترام به نگرش مالی طرف مقابل |
| **انعطاف** | پذیرش تفاوت‌ها                |
| **آینده**  | برنامه مالی مشترک             |

### Red Flags

- پنهان‌کاری مالی
- کنترل‌گری مالی
- عدم شفافیت
- سرزنش طرف مقابل

### Green Flags

- گفتگو درباره تفاوت‌ها
- توافق مشترک
- شفافیت مالی
- انعطاف در مدیریت

## سناریو ۲ — بیکاری

### هدف سناریو

### وضعیت

### سؤالات

2. چه برنامه‌ای برای مدیریت هزینه‌ها دارید؟
3. اگر بیکاری طولانی شود، چه می‌کنید؟
4. چگونه روحیه طرف مقابل را حفظ می‌کنید؟

### تحلیل

| جنبه       | نکات کلیدی                |
| ---------- | ------------------------- |
| **حمایت**  | حمایت عاطفی و مالی        |
| **مدیریت** | کاهش هزینه‌ها، جستجوی شغل |
| **صبر**    | تحمل دوره بیکاری          |
| **آینده**  | برنامه مشترک              |

### Red Flags

- سرزنش طرف مقابل
- ناامیدی سریع
- عدم حمایت
- فشار بیش از حد

### Green Flags

- حمایت متقابل
- برنامه مدیریت بحران
- صبر و همدلی
- جستجوی راه‌حل مشترک

3. اگر بیماری طولانی شود، چه برنامه‌ای دارید؟
4. چگونه تعادل بین مراقبت و زندگی شخصی را حفظ می‌کنید؟

## سناریو ۴ — مهاجرت

### هدف سناریو

بررسی چگونگی رسیدن به تصمیم مشترک وقتی فرصت فردی و نزدیکی به خانواده در تعارض‌اند.

### وضعیت

فرصت شغلی خوبی در کشور دیگری فراهم می‌شود، اما مهاجرت نیازمند دور شدن از خانواده‌هاست.

### سؤالات

1. چگونه این تصمیم را می‌گیرید؟
2. اگر یکی موافق و دیگری مخالف باشد، چه می‌کنید؟
3. چه عواملی را در تصمیم‌گیری در نظر می‌گیرید؟
4. اگر مهاجرت شکست بخورد، چه برنامه‌ای دارید؟

### تحلیل

| جنبه            | نکات کلیدی             |
| --------------- | ---------------------- |
| **تصمیم‌گیری**  | مشترک، آگاهانه         |
| **مذاکره**      | در نظر گرفتن نظر هر دو |
| **برنامه‌ریزی** | برنامه A و B           |
| **خانواده**     | مدیریت فاصله           |

### Red Flags

- تصمیم یک‌طرفه
- عدم در نظر گرفتن نظر همسر
- بی‌برنامگی
- نادیده گرفتن خانواده

### Green Flags

- تصمیم مشترک
- برنامه‌ریزی دقیق
- در نظر گرفتن همه عوامل
- انعطاف‌پذیری

## سناریو ۵ — اختلاف با خانواده

### وضعیت

یکی از خانواده‌ها (پدر، مادر، خواهر، برادر) در زندگی مشترک شما دخالت می‌کند.

### سؤالات

1. چگونه با این موضوع برخورد می‌کنید؟
2. اگر همسرتان از خانواده‌اش دفاع کند، چه می‌کنید؟
3. چگونه مرزها را مشخص می‌کنید؟
4. اگر دخالت ادامه یابد، چه اقدامی می‌کنید؟

### تحلیل

| جنبه        | نکات کلیدی               |
| ----------- | ------------------------ |
| **مرزبندی** | مشخص کردن مرزها          |
| **احترام**  | احترام به خانواده‌ها     |
| **حمایت**   | حمایت از همسر            |
| **گفتگو**   | گفتگوی مستقیم و محترمانه |

### Red Flags

- دفاع یک‌طرفه از خانواده
- عدم حمایت از همسر
- عدم مرزبندی
- تقابل

### Green Flags

- حمایت از همسر
- مرزبندی محترمانه

- تصمیم مشترک

## سناریو ۶ — تربیت فرزند

### هدف سناریو

بررسی توان توافق درباره ارزش‌ها و شیوه‌های تربیتی وقتی دو نگاه متفاوت وجود دارد.

### وضعیت

شما و همسرتان درباره نحوه تربیت فرزند اختلاف نظر دارید. یکی سخت‌گیرتر است و دیگری آسان‌گیرتر.

### سؤالات

1. اولین اقدام شما چیست؟
2. چگونه به توافق می‌رسید؟
3. اگر فرزندتان از اختلاف شما برای گرفتن چیزی استفاده کند (مثلاً از یکی چیزی بخواهد که دیگری رد کرده)، چه می‌کنید؟
4. اگر اختلاف ادامه یابد، چه اقدامی می‌کنید؟

### تحلیل

| جنبه       | نکات کلیدی              |
| ---------- | ----------------------- |
| **گفتگو**  | گفتگوی آرام             |
| **توافق**  | رسیدن به راه‌حل مشترک   |
| **انسجام** | یکسان بودن رفتار والدین |
| **مشاوره** | کمک تخصصی در صورت نیاز  |

### Red Flags

- اختلاف علنی در حضور فرزند
- تضعیف یکدیگر
- عدم انسجام
- عدم گفتگو

### Green Flags

- گفتگوی خصوصی
- توافق مشترک
- انسجام در تربیت
- پذیرش مشاوره

## سناریو ۱۲ — خیانت

### هدف سناریو

شناخت نگاه هر طرف به وفاداری، اعتماد و امکان یا عدم امکان ترمیم رابطه.

### وضعیت

یکی از شما متوجه می‌شود که طرف مقابل، خیانت عاطفی یا جسمی کرده است.

> این سناریو حساس است؛ اگر برای یکی از شما دردناک بود، می‌توانید آن را کنار بگذارید.

### سؤالات

1. اولین واکنش شما چیست؟
2. آیا ممکن است ببخشید؟ چه چیزی این را ممکن یا غیرممکن می‌کند؟
3. چه شرایطی برای ادامه رابطه لازم است؟
4. اگر ادامه دهید، چگونه اعتماد را بازسازی می‌کنید؟

### تحلیل

| جنبه       | نکات کلیدی     |
| ---------- | -------------- |
| **واکنش**  | آرامش و تفکر   |
| **گفتگو**  | گفتگوی صادقانه |
| **مشاوره** | کمک تخصصی      |
| **تصمیم**  | تصمیم آگاهانه  |

### Red Flags

- انکار خیانت
- سرزنش قربانی
- عدم پذیرش مسئولیت
- تکرار خیانت
- فشار برای بخشیدن
- خشم، تهدید یا خشونت پس از کشف

### Green Flags

- پذیرش مسئولیت
- صداقت کامل
- پذیرش مشاوره
- تلاش برای بازسازی اعتماد
- احترام به حق طرف مقابل برای ادامه یا پایان رابطه

2. اگر نظرها متفاوت باشد، چه می‌کنید؟
3. چگونه پیامدهای احتمالی را مدیریت می‌کنید؟
4. اگر تصمیم اشتباه باشد، چه می‌کنید؟

### تحلیل

| جنبه           | نکات کلیدی             |
| -------------- | ---------------------- |
| **تصمیم‌گیری** | مشترک و آگاهانه        |
| **مذاکره**     | در نظر گرفتن نظر هر دو |
| **برنامه**     | برنامه A و B           |
| **پذیرش**      | پذیرش پیامدها          |

### Red Flags

- تصمیم یک‌طرفه
- عدم مذاکره
- بی‌برنامگی
- عدم پذیرش مسئولیت

### Green Flags

- تصمیم مشترک
- مذاکره سازنده
- برنامه‌ریزی دقیق
- پذیرش مسئولیت

---

## سناریو ۱۴ — اختلاف تشدید می‌شود

### هدف سناریو

بررسی توان توقف، ایمنی و مسئولیت‌پذیری وقتی اختلاف به فریاد، تهدید یا ترس می‌رسد.

### وضعیت

در یک اختلاف جدی، صدای یکی از شما بالا می‌رود و طرف مقابل احساس ترس یا تهدید می‌کند.

### سؤالات

1. اولین اقدام شما برای توقف تنش چیست؟
2. اگر طرف مقابل احساس ترس کند، چه می‌کنید؟
3. چه قاعده‌ای برای توقف و بازگشت به گفتگو دارید؟
4. اگر این الگو تکرار شود، چه کسی و چگونه کمک می‌گیرید؟

### تحلیل

| جنبه        | نکات کلیدی                                    |
| ----------- | --------------------------------------------- |
| **توقف**    | بیرون رفتن و آرام شدن، با قول بازگشت به گفتگو |
| **مسئولیت** | پذیرش نقش خود در تشدید تنش                    |
| **ایمنی**   | احترام به احساس ترس طرف مقابل                 |
| **کمک**     | مشاوره یا فرد مورد اعتماد                     |

### Red Flags

- تهدید یا ترساندن
- سرزنش طرف مقابل به خاطر ترسش
- انکار یا کوچک شمردن ماجرا
- ادامه فریاد و تحقیر
- خشونت جسمی

> اگر در این سناریو نشانه‌ی خشونت یا ترس واقعی دیدید، [راهنمای نشانه‌های هشدار](../04-evaluation-guide/03-red-flags.md) را ببینید و ایمنی را در اولویت قرار دهید.

### Green Flags

- توقف و آرام‌شدن
- پذیرش مسئولیت
- احترام به احساس ترس طرف مقابل
- پذیرش مشاوره

---

## سناریو ۱۵ — پنهان‌کاری مالی کشف می‌شود

### هدف سناریو

بررسی واکنش به پنهان‌کاری مالی: گفتگو و ترمیم در برابر اتهام یا کنترل.

### وضعیت

متوجه می‌شوید یکی از شما بدهی یا هزینه‌ی مهمی را از دیگری پنهان کرده است.

### سؤالات

1. اولین واکنش شما چیست؟
2. چگونه موضوع را مطرح می‌کنید؟
3. چه چیزی برای بازسازی اعتماد لازم است؟
4. چه قاعده‌ی مالی مشترکی برای آینده می‌گذارید؟

### تحلیل

| جنبه           | نکات کلیدی                      |
| -------------- | ------------------------------- |
| **صداقت**      | پذیرش و توضیح کامل              |
| **گفتگو**      | طرح موضوع بدون اتهام            |
| **اعتماد**     | اقدام‌های مشخص برای ترمیم       |
| **قاعده مالی** | شفافیت و تصمیم مشترک برای آینده |

### Red Flags

- انکار یا کوچک شمردن
- تحقیر یا تهدید
- تنبیه مالی (قطع دسترسی به پول)
- تکرار پنهان‌کاری

### Green Flags

- پذیرش مسئولیت
- شفافیت کامل
- برنامه مشترک بازپرداخت
- قاعده شفافیت برای آینده

---

## سناریو ۱۶ — یکی جدایی را مطرح می‌کند

### هدف سناریو

بررسی توان گفتگو و تصمیم با احترام وقتی یکی از دو نفر جدایی را مطرح می‌کند.

### وضعیت

پس از مدتی اختلاف، یکی از شما می‌گوید ادامه‌ی رابطه برایش ممکن نیست.

### سؤالات

1. اولین واکنش شما چیست؟
2. چگونه گوش می‌دهید و چه می‌پرسید؟
3. پیش از تصمیم نهایی چه چیزهایی را امتحان می‌کنید (مثلاً مشاوره یا زمان بیشتر)؟
4. اگر تصمیم جدایی قطعی شد، چگونه با احترام و مسئولیت‌پذیری عمل می‌کنید (فرزند، مالی، خانواده)؟

### تحلیل

| جنبه              | نکات کلیدی                         |
| ----------------- | ---------------------------------- |
| **گوش دادن**      | شنیدن دلیل بدون دفاع               |
| **زمان و مشاوره** | فرصت مشخص و کمک تخصصی              |
| **احترام**        | حفظ احترام حتی در پایان            |
| **مسئولیت**       | توافق درباره فرزند، مالی و خانواده |

### Red Flags

- تهدید یا فشار برای ماندن
- تحقیر یا سرزنش
- استفاده از فرزند یا پول به‌عنوان ابزار فشار
- ناپدید شدن بدون گفتگو

> اگر پاسخ‌ها شامل تهدید یا ترس بود، ایمنی در اولویت است ([راهنمای نشانه‌های هشدار](../04-evaluation-guide/03-red-flags.md)).

### Green Flags

- گوش دادن
- پذیرش حق تصمیم هر فرد
- تلاش مشترک در صورت امکان
- پایان محترمانه

---

## جمع‌بندی فصل

پس از بحث درباره سناریوها، بررسی کنید:

- ☐ آیا در سناریوهای ایمنی و جدایی (۱۴ و ۱۶) هر دو نفر احترام و ایمنی را در اولویت قرار دادند؟
- ☐ آیا در هر سناریو، توانستید به راه‌حل مشترک برسید؟
- ☐ آیا تفاوت‌های اساسی در نحوه مدیریت بحران‌ها مشاهده شد؟
- ☐ آیا در برخی سناریوها نشانه‌های هشدار مشاهده شد؟
- ☐ آیا درباره برخی سناریوها نیاز به گفتگوی بیشتر وجود دارد؟
- ☐ آیا توانایی همکاری در شرایط سخت را دارید؟
