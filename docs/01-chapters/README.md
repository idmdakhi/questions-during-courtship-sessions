## درباره این بخش

این بخش، هسته اصلی راهنما را تشکیل می‌دهد. ۲۱ فصل، از موضوعات ساده و عمومی شروع شده و تدریجاً به موضوعات عمیق و حساس می‌رسد.

هر فصل شامل بخش‌های زیر است:

| بخش                       | توضیح                                  |
| ------------------------- | -------------------------------------- |
| **هدف فصل**               | چرا این فصل طراحی شده است.             |
| **زمان مناسب**            | در کدام جلسه مطرح شود.                 |
| **مخاطب**                 | دختر، پسر یا هر دو.                    |
| **سؤالات اصلی**           | سؤالات کلیدی با ذکر هدف هر سؤال.       |
| **سؤالات موقعیتی**        | سناریوهای واقعی برای ارزیابی رفتار.    |
| **سؤالات پیگیری**         | برای عمیق‌تر کردن گفتگو.               |
| **نکات قابل مشاهده**      | رفتارها و نشانه‌های قابل توجه.         |
| **راهنمای تفسیر پاسخ‌ها** | نشانه‌های مثبت، نیازمند بررسی و هشدار. |
| **جمع‌بندی فصل**          | چک‌لیست ارزیابی پایان فصل.             |

## نکات مهم

> **ترتیب فصل‌ها را رعایت کنید.**

فصل‌ها از ساده به عمیق چیده شده‌اند. رعایت این ترتیب، از ایجاد اضطراب زودهنگام جلوگیری می‌کند و اعتماد تدریجی ایجاد می‌کند.

> **هر فصل را در زمان مناسب خود مطرح کنید.**

در ابتدای هر فصل «زمان مناسب» ذکر شده است. مطرح کردن موضوعات حساس در زمان نامناسب، می‌تواند به سوءتفاهم منجر شود.

> **به اهداف هر سؤال توجه کنید.**

ذیل هر سؤال، «هدف» آن ذکر شده است. این کار به شما کمک می‌کند بدانید چرا می‌پرسید و پاسخ‌ها را بهتر تفسیر کنید.
