# یادداشت علمی و حدود ادعاها

> **این راهنما ابزار ساختاردهی به گفتگوست، نه ابزار روان‌سنجی اعتبارسنجی‌شده.**

---

## این راهنما چه چیزی هست و چه چیزی نیست؟

**هست:**

- چارچوبی برای اینکه موضوعات مهم پیش از ازدواج فراموش نشوند.
- مجموعه‌ای از سؤال‌های باز که گفتگوی صادقانه را آسان‌تر می‌کند.
- ابزاری برای یادداشت‌برداری، مقایسه و مرور تصمیم.

**نیست:**

- آزمون یا پرسشنامه‌ای که روایی و پایایی آن در پژوهش سنجیده شده باشد.
- ابزاری برای «پیش‌بینی موفقیت ازدواج» یا امتیازدهی قطعی به افراد.
- جایگزین مشاوره، ارزیابی بالینی یا مشاوره حقوقی.

بنابراین امتیازها و نمودارهای فصل ۲۱ **ابزار کمکی برای تفکر** هستند و عدد آن‌ها معنای آماری یا بالینی ندارد.

---

## درباره مصاحبه رفتاری (STAR)

سؤال‌های فصل ۱۸ از قالب «مصاحبه رفتاری» الهام گرفته‌اند؛ روشی که در مصاحبه‌های شغلی رایج است و از فرد می‌خواهد درباره **رفتار واقعی گذشته‌اش** (موقعیت، وظیفه، اقدام، نتیجه) صحبت کند. منطق آن این است که گفتن «آخرین باری که ... چه کردید؟» معمولاً اطلاعات عینی‌تری از «چه می‌کنید؟» می‌دهد.

**حد ادعا:** این قالب برای مصاحبه استخدامی طراحی شده است. استفاده از آن در شناخت پیش از ازدواج یک **کاربرد اقتباسی** است و برای این منظور اعتبارسنجی نشده است.

---

## درباره آزمون‌های پیوست «ز»

| آزمون                                | وضعیت                                                                                 | نکته                                                  |
| ------------------------------------ | ------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| پنج عامل بزرگ (Big Five)             | از چارچوب‌های پژوهشی پذیرفته‌تر در روان‌شناسی شخصیت                                   | نتایج برای گفتگو مفید است، نه برای «ردّ یا تأیید» فرد |
| MBTI                                 | کاربرد گسترده، اما از نظر پایایی بازآزمون و اعتبار پیش‌بینی مورد انتقاد پژوهشگران است | مناسب بازی گفتگو؛ نامناسب برای تصمیم                  |
| زبان‌های عشق                         | محبوب، اما شواهد تجربی برای اثر «هماهنگ‌کردن زبان عشق» محدود است                      | به‌عنوان زبان مشترک گفتگو مفید، نه نقشه قطعی          |
| ENRICH، ۱۶PF، NEO-PI-R، MMPI، SCL-90 | ابزارهای تخصصی                                                                        | باید با راهنمایی متخصص اجرا و تفسیر شوند              |

آزمون‌های بالینی (مانند SCL-90 و MMPI) **برای ارزیابی طرف مقابل توسط افراد غیرمتخصص طراحی نشده‌اند.**

---

## چگونه از این راهنما مسئولانه استفاده کنیم؟

1. نتیجه‌ها را «فرضیه برای گفتگو» بدانید، نه حکم.
2. هر نگرانی را با پرسش مستقیم و محترمانه بررسی کنید.
3. تصمیم را فقط بر یک عدد یا یک پاسخ نگذارید.
4. در موارد جدی (خشونت، اعتیاد، بیماری درمان‌نشده، ترس از طرف مقابل) با متخصص مشورت کنید.
